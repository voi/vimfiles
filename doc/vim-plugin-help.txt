						string (default `'□'`)

	icon letter indecating the tabe page.
	show in tab-line.

						string (default `'■'`)

	icon letter indecating the active tabe page.
	show in tab-line.

*g:vimrc_info_icon_ro*
						string (default `'❎'`)

	icon letter indicating that a current buffer is read-only or not.
	show in status-line.

*g:vimrc_info_icon_mod*
						string (default `'⚡'`)

	icon letter indicating that a current buffer is modified or not.
	show in tab-line and status-line.

fuzzy_choice_glob.vim

*g:fuzzy_choice_glob_max_candidates*
						? (default 10000)

	The maximum number of files that can be recursively listed by the
	|FuzzyChoiceMru| command.

*g:fuzzy_choice_glob_regex_ignore_dir*
						string (default `'\v^\.%(git|jj|svn|hg|bzr)$'`)

	A regular expression that matches file names to be ignored when listing
	files using the |FuzzyChoiceMru| command.

*g:fuzzy_choice_glob_regex_ignore_file*
						string (default `'\v^_FOSSIL_$'`)

	A regular expression that matches directory names to be ignored when
	listing files using the |FuzzyChoiceMru| command.

*g:fuzzy_choice_vim_mru_bookmark*
						string (default `'~/.vim_fuzzy_choice_mru_bookmark.txt'`)

	A file in the file list used as a bookmark. When you enter the
	|FuzzyChoiceMru| command, the contents of the bookmark file list are
	listed as suggestions.

markdown.vim

*g:markdown_latex_syntax_enabled*
						? (default 1)

	When not 0, LaTex syntax is enabled.
	When 0, LaTex syntax is disabled.

*g:markdown_gfm_extension_syntax_enabled*
						? (default 1)

	When not 0, GFM extension syntax is enabled.
	When 0, GFM extension syntax is disabled.

	- 4.10 Tables (extension)
	- 5.3 Task list items (extension)
	- 6.5 Strikethrough (extension)

*g:markdown_github_wiki_syntax_enabled*
						? (default 1)

	When not 0, github wiki syntax is enabled.
	When 0, github wiki syntax is disabled.

	- mention
	- issue

*g:markdown_match_pattern_reasonable*
						? (default 1)

*g:markdown_link_reference_cchar*
						string (default '')

	When not '', the link reference syntax becomes “conceal,” and the
	specified characters are used.

*g:markdown_link_destination_cchar*
						string (default '')

	When not '', the link destination syntax becomes “conceal,” and the
	specified characters are used.

*g:markdown_link_title_cchar*
						string (default '')

	When not '', the link title syntax becomes “conceal,” and the
	specified characters are used.

*g:markdown_list_item_cchar*
						string (default '')

	When not '', the list item syntax becomes “conceal,” and the
	specified characters are used.

*g:markdown_list_todo_cchar*
						string (default '')

	When not '', the unchecked task list item syntax becomes “conceal,”
	and the specified characters are used.

*g:markdown_list_done_cchar*
						string (default '')

	When not '', the checked task list item syntax becomes “conceal,”
	and the specified characters are used.

*g:markdown_task_done_include_inlines*
						? (default 0)

*g:markdown_strong_emphasis_oneline*
						? (default 0)

	When 0, the strong emphasis syntax is valid only within a single
	line.
	When not 0, the strong emphasis syntax is valid across multiple lines.
